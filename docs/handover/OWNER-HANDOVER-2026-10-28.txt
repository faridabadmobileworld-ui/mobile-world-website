11. Product data का permanent rule लागू करो।

ONE SPECIFICATION = ONE INDEPENDENT FIELD.

RAM और storage, CPU count और clock speed, Wi-Fi और Bluetooth, main camera OIS और telephoto OIS, optical और digital zoom, OS और UI, wired और wireless charging अलग fields रहें।

UNKNOWN VALUE = सच में blank.
Unknown value में “N/A”, “Unknown”, “Coming soon”, “Contact store”, dash, zero, “No” या guessed default मत भरो। Existing storage की compatibility रखते हुए actual empty representation अपनाओ।

Public product prices default hidden रहें। Internal price manage हो सकता है, लेकिन private price को public HTML, structured data, page payload या API में leak मत करना। Product schema के लिए invented price/rating/review मत डालना।
